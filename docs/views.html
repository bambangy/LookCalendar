Each view is a standalone renderer — mount it without lkCalendar() at all, and drive it from your own store and your own toolbar.

One store, four views — no orchestrator

This demo never touches lkCalendar(). It builds a createCalendarStore() directly and mounts whichever view renderer is selected below, with a hand-rolled prev/today/next.

Ready.

JavaScript

import { createMonthView, createTimeGridView, createAgendaView, createCalendarStore } from '@lookui/calendar';

const store = createCalendarStore({ events: [ /* ... */ ] });

const view = createMonthView(document.querySelector('#grid'), {
  weekStartsOn: 1,
  onSelect: ({ start, end }) => store.add({ title: 'New event', start, end, allDay: true }),
  onEventClick: (event) => console.log('clicked', event.title),
  onEventMove: (event, { start, end }) => store.update(event.masterId || event.id, { start, end }),
  onShowMore: (day, events) => console.log(events.length, 'more events on', day),
});

function render(date) {
  // compute [rangeStart, rangeEnd] for the visible grid yourself, e.g. with the
  // monthGridDays()/startOfWeek()/startOfDay() helpers exported as calendarDateMath
  const instances = store.between(rangeStart, rangeEnd);
  view.render(date, instances, store.calendars());
}

Month view: continuous bar vs. per-day blocks

A multi-day event (an all-day span, or a recurring series that lands on consecutive days) can render as one seamless bar across its days, or as a separate chip per day. Toggle it below. In 'continuous' mode it's a single chip, planted on the bar's starting day and stretched to visually span every day it crosses — no repeated title per day, no seam at the day boundaries, and the full multi-day width for the time/title to use.

JavaScript

lkCalendar('#calendar', {
  multiDayStyle: 'continuous', // or 'block'
});

Event chips: start–end time, icons, and compact collapsing

A timed event chip shows two lines — the time range (with an optional icon) on the first line, the title on the second. When the chip is too small (packed next to other events, or a short duration in week/day view) it collapses to a single compact line; hovering or focusing it pops it back to two lines, overlaying its neighbors instead of reflowing the whole grid. Icons come from either a per-event icon field or a calendar-level eventIcon(event) template, and can be a @lookui/core icon name, an emoji, an image URL, raw HTML, or any DOM node. The built-in create/edit form (createEventForm()) also ships with Icon and Color fields by default, so end users can pick one without any custom template — see Customization.

JavaScript

lkCalendar('#calendar', {
  // Fallback icon for events that don't set their own `icon` — event.icon always wins.
  eventIcon: (event) => (event.calendarId === 'urgent' ? 'alert-triangle' : null),
  events: [
    { title: 'Design review', icon: 'users', start, end },        // @lookui/core icon name
    { title: 'Launch', icon: { emoji: '🚀' }, start, end },        // emoji
    { title: 'Client call', icon: { url: '/avatar.png', alt: 'Client' }, start, end }, // image
  ],
});
