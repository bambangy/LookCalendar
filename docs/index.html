A modular, imperative calendar & scheduler built on @lookui/core — month/week/day/agenda views, drag-to-create, drag-to-move, resize, recurrence, and a customizable built-in event form. Every demo on this site is the real, running library — not a mockup.

Editable event colors

Every event gets a random, stable color by default (autoColor: true, the default) unless its calendar or the event itself sets one. Pick a color for any event below — it updates the calendar immediately.

JavaScript

import { lkCalendar } from '@lookui/calendar';

const calendar = lkCalendar('#calendar', {
  view: 'month',
  calendars: [
    { id: 'work', name: 'Work', color: '#5c6bc0' },
    { id: 'personal', name: 'Personal', color: '#00bcd4' },
  ],
  events: [
    {
      calendarId: 'work',
      title: 'Daily standup',
      start: '2026-03-02T09:00:00',
      end: '2026-03-02T09:15:00',
      recurrence: { freq: 'weekly', byWeekday: [1, 2, 3, 4, 5] },
    },
  ],
  onCreate(event) { console.log('created', event); },
  onChange(event) { console.log('updated', event); },
  onRemove(event) { console.log('removed', event); },
});

Install — getting started

@lookui/core is a peer dependency — install both, and load its look.css before look-calendar.css. LookCalendar styles itself entirely with LookUI's own design tokens and components (buttons, modal, inputs, icons) — nothing to theme twice.

Install

npm install @lookui/core @lookui/calendar

HTML

<link rel="stylesheet" href="node_modules/@lookui/core/dist/look.css">
<link rel="stylesheet" href="node_modules/@lookui/calendar/dist/look-calendar.css">

<div id="calendar"></div>
<script type="module">
  import { lkCalendar } from '@lookui/calendar';
  lkCalendar('#calendar', { /* ... */ });
</script>

Design — modular by design

lkCalendar() is a thin composition of pieces that are each independently usable — import the whole orchestrator, or just the data layer, just one view, or just the built-in form. See Views for using a renderer on its own, and each piece's own complete API reference (full options/properties/methods, not just a usage snippet) in the list below. 

import {
  lkCalendar,           // the whole thing: toolbar + view + built-in CRUD dialog
  createCalendarStore,  // just the event/calendar data model
  createMonthView,      // just the month grid renderer
  createTimeGridView,   // just the week/day renderer
  createAgendaView,     // just the list renderer
  createEventForm,      // just the built-in create/edit form
  exportICS, importICS, // interop with Google Calendar / Outlook / Apple Calendar
} from '@lookui/calendar';
  • lkCalendar — the orchestrator's full API reference
  • createCalendarStore — the data layer's full API reference
  • createMonthView / createTimeGridView / createAgendaView — each view renderer's full API reference
  • createEventForm — the built-in form's full API reference
  • exportICS / importICS — the .ics interop functions' full API reference

What's built-in

Four views Month, week, day, agenda — switch with the toolbar or calendar.changeView(). Drag interactions Drag-to-create, drag-to-move, and resize (week/day) an event's edge. Recurrence Daily/weekly/monthly rules with interval, until, count, byWeekday, exdates. Built-in CRUD form Backed by lkForm/lkDate/lkDropdown/lkCheckbox — swap its markup with your own template. before* guard hooks Same convention as every LookUI component — veto or replace any create/change/remove/navigate. Themed via LookUI tokens No parallel palette — every color/radius/spacing resolves through --lk-*. Dark mode just works. Auto event color An uncolored event gets a stable, random-looking color (autoColor, on by default) instead of every event looking the same — see the picker above. Marked days Color weekends, public holidays or blackout dates with markedDays — no event required. Full color overrides Header, date, time, event, today and selection each have their own --lkc-* token — retarget any one without side effects. Keyboard accessible Event chips are focusable (Enter/Space opens them); month view's day grid is a roving-tabindex grid (arrow keys, Enter/Space to create). Every toolbar control and the agenda list were already native buttons. Timezone support opts.timezone pins "today", every view's day/week/month boundaries, displayed times and recurring events' cadence to an IANA zone — independent of the viewer's own machine, and DST-safe. .ics import/export exportICS() / importICS() — interop with Google Calendar, Outlook and Apple Calendar via the same RFC 5545 format they all read and write.
