The built-in create/edit dialog is createEventForm() — built entirely on @lookui/core. Replace its markup without losing the wiring.

Try it — default vs. custom event form

Click an event (or drag to create one) to open the dialog. Toggle below to swap in a custom template that adds a "Location" field — same calendar, same store, different form markup. The default form ships with Icon and Color fields already wired — pick an icon from a curated @lookui/core icon list (an lkDropdown) and a color (an lkColor swatch+picker), both optional and both cleared back to "inherit from calendar/auto" by default.

Click an event, or drag-create a new one, to try the form.

JavaScript

lkCalendar('#calendar', {
  eventForm({ event, calendars, t }) {
    return `
      <div class="lkc-form__row">
        <label class="lkc-form__label">${'${t(\'form.title\')}'}</label>
        <input class="lk-input" name="title" placeholder="${'${t(\'form.titlePlaceholder\')}'}" />
      </div>
      <div class="lkc-form__row lkc-form__row--split">
        <div><label class="lkc-form__label">${'${t(\'form.starts\')}'}</label>
          <input class="lk-input" type="text" data-field="start" readonly /></div>
        <div><label class="lkc-form__label">${'${t(\'form.ends\')}'}</label>
          <input class="lk-input" type="text" data-field="end" readonly /></div>
      </div>
      <div class="lkc-form__row">
        <label class="lkc-form__label">${'${t(\'form.calendar\')}'}</label>
        <select name="calendarId"></select>
      </div>
      <!-- your own extra field, outside the built-in contract -->
      <div class="lkc-form__row">
        <label class="lkc-form__label">Location</label>
        <input class="lk-input" name="location" value="${'${event?.location ?? \'\'}'}" />
      </div>
    `;
  },
});

Try it — a different form for creating vs. editing

eventForm replaces the markup for both dialogs. Pass newEventForm and/or editEventForm instead to use entirely separate templates for each — e.g. a fast "just a title" quick-add, and a fuller edit form once the event already exists. Pick "Separate create / edit forms" above to try it: drag-create a new event (quick form, title only) vs. click an existing one (full form, with Location and Description).

JavaScript

lkCalendar('#calendar', {
  // Creating: fast, minimal — just enough to get the event on the calendar
  newEventForm({ t }) {
    return `
      <div class="lkc-form__row">
        <label class="lkc-form__label">${'${t(\'form.title\')}'}</label>
        <input class="lk-input lkc-form__input" name="title" placeholder="${'${t(\'form.titlePlaceholder\')}'}" autofocus />
      </div>
      <!-- no start/end/calendar fields: the drag-selection already set them -->
    `;
  },
  // Editing: the full form, plus your own extra fields
  editEventForm({ event, t }) {
    return `
      ...full template with title, start, end, calendar, location, description...
    `;
  },
});

Prefer one function that branches instead of two options? A function eventForm template also receives mode: 'create' | 'edit' in its context, so eventForm(({ mode }) => mode === 'create' ? quickMarkup : fullMarkup) works too.

Reference — field contract

Any field your template omits is simply left unwired.

SelectorBecomes
[name="title"]plain text input/textarea
[name="allDay"]lkCheckbox
[data-field="start"]lkDate (time mode) popup trigger
[data-field="end"]lkDate (time mode) popup trigger
[name="calendarId"]lkDropdown, populated from opts.calendars
[name="icon"]lkDropdown over a curated @lookui/core icon-name list — see Views
[name="color"]lkColor swatch + picker
[name="description"]plain textarea (optional)

Extra fields (like location above) aren't part of getValues()'s fixed return shape — read them from form.form.getValues() (the raw lkForm values) or query form.el directly.

Standalone — using createEventForm() without a calendar

JavaScript

import { createEventForm } from '@lookui/calendar';

const form = createEventForm({
  event: { title: 'Review', start: new Date(), end: new Date(Date.now() + 3600000) },
  calendars: [{ id: 'work', name: 'Work' }],
});

document.body.appendChild(form.el);
saveButton.addEventListener('click', () => {
  if (!form.validate()) return;
  console.log(form.getValues()); // { title, allDay, start, end, calendarId, icon, color, description }
});
// later: form.destroy();
